# Client visual-speech (lip-reading) evaluation — repeatable pipeline

One command turns a client's raw conversation videos into the full deliverable set:

    active-speaker crops → stacked streams → per-turn decode → script alignment → scoring
      → per-video "what is understood" → confidence-colored "said vs heard" videos
      → sample clips → stats plots → client deck

Orchestrator: `scripts/pipeline/client_lipread_eval.py --config <dataset>.json`
Worked example config: `datasets/clients/egla_kafe/eval_config.json`.

    python3 scripts/pipeline/client_lipread_eval.py --config datasets/clients/egla_kafe/eval_config.json
    # or a subset / resume:
    python3 scripts/pipeline/client_lipread_eval.py --config <cfg> --stages streams,segments,decode
    python3 scripts/pipeline/client_lipread_eval.py --config <cfg> --from-stage align

## The one thing a new dataset must provide: the canonical index
Everything downstream reads `<work>/eval/index.json`:

```
{"entries": [
  {"stem": "<ascii-safe id>",              # used in all filenames/seg-ids (NO spaces/Hebrew)
   "orig_path": "<abs path to source video>",
   "source_type": "scene_recording"|"master"|...,   # any label; "master" = treat as high-res/alt-angle
   "scene": "scene1"|...|null,             # which script this video reads (null => auto-detect at align)
   "script": "script1"|null,
   "angle": "front"|"30"|"45"|"master"|..., # for per-angle stats
   "speakers_in_name": ["tomer","yoad"],    # the pair, for face-ID constraint naming
   "existing_crops": {"left": "<path>"|null, "right": "<path>"|null}}  # reuse if present; else auto-cropped
]}
```

Build it with a **dataset-specific indexer** (reference: `scripts/pipeline/egla_kafe_index.py`, which
parses Hebrew filenames + folder→scene map + discovers hand-made crops) set as `"indexer"` in the config,
or hand-write it. Scripts are parsed from raw `Speaker: line` dialogue txts via `parse_dialogue_script.py`
into `<work>/eval/script_<scene>.json`.

## Stages (each is a tested tool; all selectable)
| stage | tool | produces |
|---|---|---|
| index | (config `indexer`) | `eval/index.json` |
| scripts | parse_dialogue_script.py | `eval/script_*.json` |
| crops | make_speaker_crops.py | per-speaker L/R crops for videos lacking them |
| faceid | egla_kafe_face_id.py | `eval/face_id.json` (who-is-who via clustering + pair constraints) |
| streams | egla_kafe_build_streams.py | active-speaker stacked stream + turns + QC per video |
| segments | egla_kafe_cut_segments.py | per-turn single-speaker clips + seg_meta |
| decode | run_flat_english_pipeline.sh (SEG=0, VSP_NBEST=1) | hypotheses + confidence + n-best; archive recorded in `eval/last_decode.json` |
| align | egla_kafe_align_and_score.py | monotonic script alignment → refs (+auto-detect script) → report.csv |
| score | analyze_egla_kafe.py | grouped stats (scene/speaker/angle/source) |
| pervideo | egla_kafe_per_video_report.py | per-video "what is understood" ranked table |
| subtitles | egla_kafe_conversation_subtitle_video.py | full-length "said vs heard" confidence-colored videos on the joint frame |
| clips / plots | egla_kafe_make_demo_clips.py / egla_kafe_{significance,deck_plots}.py | deck sample clips + figures |

Outputs land under `<deliverables_root>/` (videos, per_video report) and `<work>/eval/` (intermediates).
The per-video PDF and the client PPTX are generated by `generate_egla_kafe_per_video_pdf.py` and
`generate_egla_kafe_client_deck.py` (the presentation layer — light per-client edits to captions/titles).

## Important constraints (carry to any new dataset)
- **Model is English-only** (Llama-2 + AV-HuBERT). Non-English footage will not produce meaningful text.
- **No audio on the scoring footage** → turn detection is **visual** (FaceMesh mouth-openness variance),
  and alignment uses the **known script** (not Whisper). With audio, swap in Whisper at the align stage.
- **Per-turn (split-speaker) segments beat feeding one continuous stream** — the model dislikes mid-clip
  speaker cuts. Keep the per-turn arm as the scoring arm.
- **Report the alignment-free conversation-level WER + IS + context-judge**, not raw per-segment WER
  (per-short-segment scoring is artificially harsh). **Confidence-gate** for deployable quality.
- **Trust the gist / common-nouns; verify names, numbers, dates** (entities are hallucinated).
